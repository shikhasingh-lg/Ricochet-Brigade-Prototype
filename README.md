## Current design state

**v1 (superseded 2026-05-20):** Slingshot-as-primary-input. Heroes spawn by flicking onto a lane. Killed for confabulated comp claims and weak differentiation — flick alone wasn't a strategic layer.

**v2 (active, design pending):** Pick-1-of-3 hero spawn + tap-to-place + tap-charged hero ults + slingshot as coin-spell secondary attack. Three mid-wave agency layers vs zero in both comp leaders.

Locked twists for v2:
- **T1** — Pick-1-of-3 spawn (spawn agency)
- **T2** — Tap-charged hero ults (mid-wave agency)
- **Coin-fueled slingshot** — secondary spell-like burst attack, choice tension with hero spawn

Open design questions tracked in the in-flight design conversation. v2 spec + UI flow + paper-test script pending lock.
